Formularios en HTML

Colección completa de elementos de formularios web

Texto

Campos de texto básicos: simple, con placeholder, obligatorio (required), de solo lectura (readonly) y deshabilitado (disabled).






Contacto

Campos especializados para datos de contacto: contraseña, correo electrónico, teléfono y URL.





Numéricos

Campos para valores numéricos: un número con límites (min/max) y un deslizador (range).



Fecha y hora

Selectores nativos de fecha y hora: fecha, fecha y hora combinadas, hora, semana y mes.






Selección

Controles de selección: color, casilla de verificación, botones de radio y archivos.




Listas desplegables (select)

Listas desplegables con el elemento select: simple, con selected, optgroup, múltiple y disabled.
